# Nundine

A simple marketplace web application where sellers can create, update and delete products and buyers can browse and purchase them.

## Features
- Create, read, update, delete (CRUD) products
- Browse product catalog
- View product details
- Purchase products
- Earn gold to buy products
- User registration and authentication via Keycloak
- Role-based access control

## Tech stack
- Backend: Java, Spring Boot
- Authentication & Authorization: Keycloak
- Frontend: Angular
- Database: PostgreSQL
- Build tools: Maven, npm/Angular CLI
